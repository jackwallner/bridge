**Why it fails:** SM-3's new rule turns off the Game Night reminder on RevenueCat's on-device cache alone, which the rules forbid ("only a fresh network 'not a member' may tear anything down"). The fixes doc says the rule "never acts on the cache alone" and "never acts offline", but the launch read uses `.cachedOrFetched`, which in 5.80.3 hands back the cached record even when it is stale and does not wait for the network. The two tests that are meant to prove the guard use a fake client that ignores the fetch policy, so they pass while the shipping path does not hold. A paying member can lose the reminder (route below). The other four fixes work.

# Localized metadata from keyword research, 2026-11-20

Ten locales rewritten: tr, nl-NL, th, da, de-DE, fr-FR, el, zh-Hant, it, en-GB. Nothing was uploaded to App Store Connect. Evidence is a snapshot from Apple search hints (autocomplete, per storefront) and the iTunes Search API (top 25), taken 2026-11-20. Ranks are for the metadata live before this change, so they are the baseline. Our listing often did not appear at all in the API for local queries even where the old name and subtitle contained the words (de, fr, nl, it, gr); treat "not in top 25" as a weak signal, and the API as unreliable for brand-new apps with 0 to 1 ratings.

Indexing, from Apple's table ([App Store localizations](https://developer.apple.com/help/app-store-connect/reference/app-information/app-store-localizations)): every storefront below indexes en-GB as its secondary locale (en-US is not indexed there). So en-GB name, subtitle and keywords reach TR, NL, TH, DK, DE, FR, GR, IT, TW and HK as well as GB. en-GB was therefore given its own English set (it no longer copies en-US) and the local locales avoid spending bytes on English words. fr-FR and zh-Hant are also indexed by the US storefront.

Competitor subtitles could not be read: apps.apple.com no longer serves the subtitle (it shows the category). Competitor titles and rating counts below come from the search API.

Common finding: demand in these storefronts is thin and mostly "bridge" + a verb (play, learn, practise). Autocomplete returned bridge-specific terms only in a few storefronts; elsewhere "bridge" suggestions were construction games, "Bridge Constructor", Bridge Race and score keepers. The bridge-card meaning is clear only when the local card noun or verb is added, so each name/subtitle pairs "bridge" with a local card or bidding word.

## tr (TR, 65 downloads in 90 days; proceeds $17)
- Autocomplete (TR): `briç` gives "briç oyna", "briç", and a competitor titled "... briç öğren". `briç ö`/`briç o` confirm "öğren" and "oyna". `iskambil` gives "iskambil oyunları/oyunu"; `kağıt oyunu` gives "kağıt oyunu", "51/101/81 kağıt oyunu". `ihale` returns tender/auction apps and "ihaleli batak", so "ihale" alone is ambiguous; it stays because the Turkish bridge term for bidding is ihale and the subtitle pairs it with savunma.
- Competitors: Fun Bridge (849 ratings), Bridge Base Online (562), Play Bridge: Offline Card Game (50), Bridge Begin: Card Game (22), a briç-named learning app (0). Thin competition for Turkish-word queries.
- Our rank (old metadata): `briç öğren` #1 of 5, `briç oyna` #4, `briç kart oyunu` #4, `briç eğitimi` #3, `briç pratik` #4, `briç` and `bridge` not in 25.
- Keywords: `oyna,oyunu,iskambil,kağıt,kart,ders,başlangıç,kontrat,deklaran,koz,löve,atak,sanzatu,quiz,eğitim`. oyna/oyunu/iskambil/kağıt are the autocomplete words. löve, koz, sanzatu (notrump), atak (lead) and deklaran are the terms the app's own Turkish strings use. Dropped English tutor/drill/bidding/practice (en-GB covers them in TR) and the vague "bilgi".
- Name unchanged: `Bridge Trainer: Briç Öğren`. Subtitle: `Briç konuşma ve kart pratiği` -> `İhale ve savunma alıştırmaları` ("briç" was repeated from the name).

## Style and copy notes
- Descriptions follow the current en-US description (the old non-English ones still described the removed 7-day trial and had the wrong privacy URL). They use the app's own localized room, feature and bridge-term strings from `Bridge/Localizable.xcstrings` so the store page matches what the user sees.
- No em dashes, no emojis, no competitor names in any field.

## Validation
- `python3 scripts/aso_field_counts.py <locales>` prints counts against limits; `python3 scripts/validate_aso_metadata.py <locales>` checks duplicate tokens: both clean for the ten locales.
- `asc migrate validate --fastlane-dir fastlane`: valid true, 0 errors, 0 warnings.
